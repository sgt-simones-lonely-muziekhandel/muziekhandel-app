# Game helpers

**Owners:** Amber, Antonio (front end)

Shared code the scenes use. Planned files:

- `state.ts`: what the player carries along: collected cylinders, current piece, the route through the data, visited places.
- `nav.ts`: one navigation system for every link (piece → composer → their other pieces → related composers), with "back".
- `world/`: walkable scenes (parallax layers, the player, clickable hotspots).
- `ui/`: paper cards, brass buttons, plaques, icons, dialogue with the shopkeeper.
- `fx/`: lamplight, rain, ash, fog, the time-travel effect.
