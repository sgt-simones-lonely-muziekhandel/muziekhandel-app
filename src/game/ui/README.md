# UI

**Owners:** Amber, Antonio (front end)

In-world interface pieces, built from `public/art/ui/`:

- paper card, brass plaque and paper strip, stretched to fit their text (Phaser `NineSlice`);
- round buttons with icons (`public/art/ui/icons/`);
- dialogue with the shopkeeper;
- the route ribbon showing the path through the data.

Text is always real text (Nunito Sans / Cinzel Decorative), never baked into images. See [the design guide](../../../docs/design/README.md).
