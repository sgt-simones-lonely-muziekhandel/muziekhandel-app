# Effects

**Owners:** Amber, Antonio (front end)

Atmosphere, using `public/art/fx/`:

- lamplight glows (additive blend, slow flicker);
- rain and ash in the future, dust and fog;
- the paper-grain/vignette overlay;
- the time-travel transition (cold grey → warm, paper peeling, notes swirling out of the cylinder). The steps are in [the design guide](../../../docs/design/README.md#time-travel-transition).
