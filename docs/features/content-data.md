# Content data: composers and pieces

The shop's sheet music and composers come from the Muziekschatten data, through [the back end](backend.md); `js/catalogue.js` turns them into the shape below (a piece without `notes` yet, a composer without `bio` or `fact`). What follows is the game's own content in `js/data.js`, which the piano, the gramophone and the lessons still use.

All composers and pieces live in one file, `js/data.js`, so content can be added without touching the game code.

## Composers

`COMPOSERS` is a list of objects:

| Field | Meaning |
|---|---|
| `id` | Short id used everywhere (`'mozart'`) |
| `name`, `short` | Full name, and the short name for plaques and shelves |
| `years`, `title` | "1756 – 1791", and a nickname ("Het wonderkind") |
| `born`, `died` | Date and place |
| `portrait` | Image path (optional; none of the composers has one now, so they all get the standard silhouette `NO_PORTRAIT`, see `portraitOf()`) |
| `bio`, `fact` | Short biography and a *Wist je dat?* fact, in simple Dutch |
| `tree` | Family (not shown any more since the composer card lost its family tree; kept in the data): `grandparents?`, `parents`, `siblings`, `spouses`, `children`, `childrenNote?`; each person is `{ name, role, years, g: 'm' \| 'f' }` |

## Pieces

`PIECES` (the shop's music: the cabinet and the cylinder chest) is `SOM_PIECES` from `js/som-scores.js`, generated by `scripts/import_scores.py` (see [real sheet music](som-scores.md)). The composers' own pieces are `DEMO_PIECES` in `js/data.js`, shown on their cards (`piecesBy()`); `ALL_PIECES` holds both, for `pieceById()`. A piece is an object:

| Field | Meaning |
|---|---|
| `id`, `title`, `subtitle` | |
| `composer` | A composer `id`, or `null` for a [real song](som-scores.md), which has `credit` / `creditShort` (its makers' names) instead |
| `level` | 1–3 stars (worked out by the import for the real songs) |
| `time` | Time signature, e.g. `[3, 4]` |
| `tempo` | Quarter notes per minute |
| `pickup` | Optional upbeat length in quarter notes (Für Elise: `0.5`) |
| `notes` | The melody as text, see below |
| `introBeats`, `accomp`, `accompGrid` | Optional piano accompaniment (real songs): `[onset, duration, midi]` in 1/`accompGrid` quarters from the start; the melody comes in `introBeats` quarters later |
| `scans` | Optional pages of the original scan: `{ dir, pages, cover }`, `pages` the page numbers in book order, the first one the cover when `cover` |
| `emblem`, `series`, `place` | Optional, for the drawn cover of a song without a printed one: the instrument (`mandolin`, `violin`), the series line (*Album voor Mandoline en Viool · No. 3*), the place at the bottom |

### Writing notes

Each note is `pitch:duration`, separated by spaces. `|` bar lines are optional and only help reading; bars are worked out from the time signature.

- Pitch: letter + optional `#` or `b` + octave, e.g. `C4` (middle C), `F#4`, `Bb3`. A rest is `r`.
- Duration: `w` whole, `h.` dotted half, `h` half, `q.` dotted quarter, `q` quarter, `8.` dotted eighth, `8` eighth, `16.` dotted sixteenth, `16` sixteenth, `32` thirty-second. Triplets (three in the time of two): `ht`, `qt`, `8t`, `16t`.
- A `~` after the duration ties the note to the next one of the same pitch (`G4:q~ G4:q`): it sounds once, as long as both, and *Speel mee* skips the second.

```js
notes: `E4:q E4:q F4:q G4:q | G4:q F4:q E4:q D4:q | C4:q C4:q D4:q E4:q | E4:q. D4:8 D4:h`
```

Notes outside C3–G5 can be written but can't be played on the on-screen piano.

`parsePiece()` in `js/music.js` turns this into notes with MIDI numbers, staff positions, start times and bar numbers (plus `type`, `dotted`, `triplet`, `tieNext` / `tied` and `sound`, the length of a tied chain), and caches the result.
