# Audio files

**Owners:** Rei, Teo (backend)

Real recordings for the gramophone, and any scores (MusicXML) used to make the note text for pieces. The piano itself plays its notes with Tone.js (`js/audio.js`), so it doesn't need files here.

## Sound effects

Made by `scripts/import_sounds.py` from the recordings in `design/sounds` (all CC0, free to use without credit), played by `js/sfx.js`:

- `steps/stone-N`, `steps/wood-N`, `steps/wet-N`: footsteps (cobbles, the shop's floor, the flooded future), five of each, from Kenney's [Impact Sounds](https://kenney.nl/assets/impact-sounds) (concrete, wood, grass).
- `time-travel/gust`, `time-travel/chime`: one 2.5 s gust of wind and a little chime, from [BigSoundBank](https://bigsoundbank.com) (*Strong wind #2*, *Chimes "Butterfly" #1*).
